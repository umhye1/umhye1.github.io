서비스 소개

사용자가 계좌와 소비 내역을 관리하고 자산 현황을 확인하는 가계부 서비스입니다. 대시보드에서 현황을 보고 거래를 입력·조회·수정하는 흐름을 제공합니다.

팀 프로젝트의 프론트엔드 담당입니다. 대시보드·거래 화면·빠른 추가 모달과 로그인 이후 화면 연결을 구현했습니다.

사용 흐름

  1. 1로그인 후 대시보드 이동
  2. 2계좌와 자산 현황 확인
  3. 3계좌 선택 후 거래 추가
  4. 4거래내역 조회 및 수정

기술 구성과 역할

Vue 3
대시보드와 거래 입력·조회·수정 화면을 구성했습니다. 화면 상태와 사용자 입력을 연결합니다.
Axios
화면에서 필요한 계좌·거래 API를 호출합니다. 호출 로직을 화면 표시 코드와 분리했습니다.
Vite
Vue 프론트엔드의 개발·빌드 환경입니다.

담당 기능 및 구현 과정

상황

거래 입력에는 먼저 계좌 정보가 필요했고, 로그인 이후 화면 이동과 거래 API를 연결해야 했습니다.

과제

대시보드·거래 조회·수정 화면과 빠른 추가 모달을 맡아 계좌 선택부터 거래 입력까지 연결했습니다.

실행

대시보드 및 거래 조회·수정 화면

Vue 3로 대시보드와 거래 조회·수정 화면을 구현했습니다. 화면 코드와 API 호출 로직을 분리하고, 조회한 데이터를 화면 상태에 연결해 거래 정보를 확인하고 수정할 수 있도록 했습니다.

빠른 거래 추가

거래 추가 모달에서 계좌를 조회하고 선택할 수 있도록 API를 연결했습니다. 계좌 선택에서 거래 입력까지 이어지도록 구성하고, 입력 스타일과 오류 안내를 정리했습니다.

로그인 이후 화면 이동

로그인 이후 필요한 화면으로 이동하는 리다이렉트와 상태 저장 흐름을 정리했습니다. 인증 이후 화면 이동과 거래 작업이 이어지도록 화면 간 연결을 구현했습니다.

결과

담당 대시보드와 거래 추가·조회·수정 화면을 구현했습니다. 화면과 API 로직의 책임을 분리하며 프론트엔드에서 데이터 흐름을 연결하는 경험을 쌓았습니다.

설계 판단

1. 화면과 API 호출 분리

화면별 API 호출 로직을 분리해 데이터 요청과 화면 표시의 책임을 나눴습니다.

2. 거래 입력 순서

거래 입력에 필요한 계좌를 먼저 조회·선택할 수 있도록 모달의 입력 흐름을 구성했습니다.
