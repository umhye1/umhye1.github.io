서비스 소개

지정헌혈이 필요한 요청자와 헌혈 참여자를 연결하는 커뮤니티 서비스입니다. 요청 게시판을 중심으로 사용자 간 대화와 프리미엄 결제 기능을 제공합니다.

프론트엔드에서 게시판·결제·실시간 채팅 연동을 담당했습니다. 전체 서버 구조나 결제 서버 검증 로직을 직접 구현한 것으로 설명하지 않습니다.

사용 흐름

  1. 1지정헌혈 요청 게시·확인
  2. 2요청자와 참여자 연결
  3. 3사용자 간 실시간 대화
  4. 4필요 시 프리미엄 결제 이용

WebSocket

KG이니시스 API
프리미엄 결제 화면에서 외부 결제 기능을 연동했습니다.

담당 기능 및 구현 과정

상황

지정헌혈 요청 게시판 외에도 사용자 간 대화와 프리미엄 결제 화면이 필요했습니다.

과제

React 게시판·결제·채팅 화면을 맡아 외부 결제 API와 WebSocket 통신을 연결했습니다.

실행

지정헌혈 요청 게시판

React로 지정헌혈 요청 게시판 화면을 구현했습니다. 요청자와 참여자가 정보를 확인하는 화면을 담당하며 팀의 기능 개발에 참여했습니다.

프리미엄 결제 화면

KG이니시스 API를 프리미엄 결제 흐름에 연결했습니다. 외부 결제 서비스를 사용하는 프론트엔드 연동을 담당했습니다.

실시간 채팅

WebSocket 기반 사용자 간 채팅을 화면에 연동했습니다. 게시판 이외에도 요청자와 참여자가 대화할 수 있는 기능을 구현하고 Git으로 팀 작업을 공유했습니다.

결과

게시판·결제·실시간 채팅을 연결하는 프론트엔드 구현에 참여했습니다. 첫 팀 프로젝트에서 외부 API와 실시간 상호작용을 다뤘습니다.

설계 판단

1. 외부 서비스 연동

결제에는 KG이니시스 API를 사용하고, 실시간 대화에는 WebSocket을 연결했습니다. 화면별 목적에 맞는 연동 방식을 적용했습니다.
