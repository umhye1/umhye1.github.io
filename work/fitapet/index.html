서비스 소개

반려동물 보호자가 동반 가능한 시설 정보를 확인하고, GPS 산책 기록과 기간별 통계를 남길 수 있는 반려동물 소셜 서비스입니다.

팀 서비스 중 회원 인증, 산책 기록·통계 API, 배포 환경을 담당했습니다. 이후 React 화면과 API 연동을 추가로 수행했습니다.

사용 흐름

  1. 1회원가입·이메일 인증 및 로그인
  2. 2반려동물 동반 시설 정보 확인
  3. 3GPS 기반 산책 기록 저장
  4. 4기간별 산책 기록·통계 확인

기술 구성과 역할

Spring Boot · Spring Security
회원 인증·인가와 산책 기록·통계 API를 구성했습니다. 요청 인증 과정에서 로그아웃 토큰의 재사용 여부도 확인합니다.
Redis
로그아웃한 Access Token의 블랙리스트 저장에 사용했습니다. 토큰의 남은 유효기간만큼 TTL을 설정해 만료 데이터를 정리합니다.
React
사용자 화면을 구성하고 백엔드 API를 연결했습니다. 프론트엔드 인원 공백 이후 일부 화면·연동 작업을 추가 담당했습니다.
AWS EC2 · S3
백엔드 배포와 파일 저장 환경을 구성했습니다.

담당 기능 및 구현 과정

상황

클라이언트가 JWT를 삭제해도 Access Token은 만료 전까지 서버에서 유효했습니다. 개발 중에는 프론트엔드 인원 공백도 생겼습니다.

과제

서버에서 로그아웃 토큰의 재사용을 거부하고, 인증·산책 API와 필요한 React 화면을 연결해야 했습니다.

실행

회원 인증 및 로그아웃

SMTP 이메일 인증과 Spring Security 인가를 구현했습니다. JWT를 클라이언트에서 삭제하는 것만으로는 서버의 토큰 유효성이 사라지지 않아, 로그아웃한 Access Token을 Redis 블랙리스트에 등록하고 후속 요청에서 확인하도록 했습니다. 토큰의 남은 유효기간을 TTL로 설정하고 Refresh Token도 삭제했습니다.

산책 기록 및 통계 API

GPS 산책 기록과 기간별 통계 API를 개발했습니다. 사용자가 산책 기록을 남기고 기간에 따라 조회할 수 있도록 백엔드 기능을 구성하고 프론트엔드의 API 사용 흐름을 연결했습니다.

서버 배포 및 파일 저장

EC2·S3 기반 배포 환경을 구성했습니다. 백엔드 실행 환경과 파일 저장 환경을 마련해 팀이 개발한 기능을 연결할 수 있도록 했습니다.

React 화면 및 API 연동

프론트엔드 팀원 하차 이후 담당 범위를 확대했습니다. 핵심 화면과 부가 기능의 우선순위를 나누고 React 화면·API 연동을 추가 수행했습니다. 작업 진행 상황과 필요한 도움을 공유하면서 서비스의 주요 흐름부터 연결했습니다.

결과

로그아웃 토큰 재사용 거부와 만료 데이터 정리 경로를 구현했습니다. 역할을 확장해 졸업 프로젝트를 완성했고 A+ 평가를 받았습니다.

설계 판단

1. 토큰 무효화 및 TTL

서버에서 로그아웃 토큰을 식별할 수 있도록 Redis 블랙리스트를 사용했습니다. 토큰 만료 후 불필요한 기록이 남지 않도록 남은 유효기간을 TTL로 적용했습니다.

2. 팀 작업 우선순위

인원 공백 이후 핵심 화면과 API 연동을 우선했습니다. 백엔드 작업과 프론트엔드 작업의 의존 관계를 고려해 연결 순서를 조정했습니다.
