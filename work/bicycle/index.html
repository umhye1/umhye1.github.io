상황

수업에서 정의한 사용자 기능을 UML 산출물과 C++ 프로그램으로 연결해야 했습니다.

과제

회원·자전거·대여의 책임을 나누고, 등록·대여의 기본 흐름을 객체 간 호출로 구현했습니다.

실행

요구사항 분석 및 UML

회원·자전거·대여를 중심으로 요구사항을 정리하고 Use Case, Communication, Class Diagram을 작성했습니다. 사용자 요청이 어떤 객체에 전달되고 각 객체가 어떤 책임을 갖는지 모델링했습니다. 반납·예약·결제 등은 요구사항과 설계 산출물에 포함했습니다.

회원 및 자전거 등록

C++에서 회원가입·로그인·자전거 등록 기능을 구현했습니다. 파일 입출력과 메모리 배열을 사용하는 콘솔 프로그램으로 구성했습니다.

자전거 대여 및 목록 출력

등록된 자전거의 대여와 목록 출력 기능을 구현했습니다. 요구사항에서 정리한 사용자 흐름을 객체 간 호출과 콘솔 입출력으로 연결했습니다. 확인된 구현은 등록·대여의 기본 흐름입니다.

결과

회원가입·로그인·자전거 등록·대여·목록 출력이 가능한 콘솔 프로그램과 UML 산출물을 완성했습니다. 요구사항, 객체 간 메시지, 실제 구현을 함께 정리하며 설계와 코드가 연결되는 과정을 경험했습니다.
